## 付録. 実行したBQクエリ（再現用・個人情報を含む列は出力していない）

**共通（全クエリ）**：`refs`＝`SELECT DATE '2026-08-31' AS ref UNION ALL SELECT DATE '2026-09-30'` をクロスジョインして2基準日を同時実行。プロジェクト`spic-com-2025-apr-00`で実行。ブランド判定は`sandbox_nishimori.shopify_sku_brand_master`（`l.sku = CAST(bm.sku AS STRING)`）。

```sql
-- 共通CTE（有償注文条件・CYS0810除外・基準日で打ち切り）
paid AS (
  SELECT so.customer_id, so.name AS order_name, DATE(so.created_at) AS d, so.line_items
  FROM `spic-core.public.shopify_orders` so
  WHERE so.test=0 AND so.cancelled_at IS NULL AND so.customer_id IS NOT NULL
    AND (so.total_price - so.current_total_tax) > 0
    AND (so.discount_codes IS NULL OR so.discount_codes NOT LIKE '%CYS0810%')
    AND DATE(so.created_at) <= '2026-09-30'
),
line AS (
  SELECT p.customer_id, p.order_name, p.d, JSON_EXTRACT_SCALAR(item,'$.sku') AS sku,
         SAFE_CAST(JSON_EXTRACT_SCALAR(item,'$.price') AS FLOAT64) AS pr,
         SAFE_CAST(JSON_EXTRACT_SCALAR(item,'$.quantity') AS FLOAT64) AS qty
  FROM paid p, UNNEST(JSON_EXTRACT_ARRAY(p.line_items)) item
),
mion AS (   -- MINERALion本品の注文（注文単位）
  SELECT l.customer_id, l.order_name, l.d
  FROM line l JOIN `spic-com-2025-apr-00.sandbox_nishimori.shopify_sku_brand_master` bm ON l.sku = CAST(bm.sku AS STRING)
  WHERE bm.brand='MINERALion' AND l.pr > 0 GROUP BY 1,2,3
),
life AS (SELECT customer_id, MIN(d) AS life_first FROM paid GROUP BY 1),
real AS (SELECT customer_id, MIN(d) AS first_real FROM line WHERE pr > 0 GROUP BY 1),
fd   AS (SELECT customer_id, MIN(d) AS first_date FROM mion GROUP BY 1),
cust AS (   -- 4区分の判定
  SELECT f.customer_id, f.first_date, DATE_TRUNC(f.first_date, MONTH) AS cm,
    (l.life_first = f.first_date) AS is_pure,
    (l.life_first < f.first_date AND r.first_real = f.first_date) AS is_trial
  FROM fd f LEFT JOIN life l USING (customer_id) LEFT JOIN real r USING (customer_id)
)
```

**Q1 5章・5-2（M+N・アイテム新規／純粋新規／トライアル先行）**：`act`＝`cust`×`mion`（`DATE_DIFF(DATE_TRUNC(m.d,MONTH), c.cm, MONTH) BETWEEN 0 AND 12`・`m.d <= ref`・`c.first_date <= ref`）を`DISTINCT`し、`COUNT(*)`／`COUNTIF(is_pure)`／`COUNTIF(is_trial)`を月×Nで集計。`grid`で観測可能なN（`DATE_DIFF(DATE_TRUNC(ref,MONTH), cm, MONTH) >= n`）のみ出力。

**Q2 周期別**：`reference_customer_analysis_queries.md` 10-2に準拠。`sandbox_nishimori.subscription_history_view`（`has_mineralion=1`・`snapshot_ym <= ref月`）から`subs`／`cs`（`ROW_NUMBER() OVER (PARTITION BY ref, cid ORDER BY first_snap, fo, subscription_id)`）を作り、`CAST(f.customer_id AS STRING) = s.cid`で結合。bucket＝`spot`（定期経験なし）／`1m`（月×1または日×28）／`2m`／`3m`／`other`（0件）。

**Q3 5-1①②（初回SKU別F2）**：`mo`＝注文単位で`has_set`（`sku='130-set'`）／`has_teiki`（`sku='130-teiki'`）／`has_multi`（`130-set-2/3/4`・`130-teiki-2/3/4`）／`has_other`（上記以外の本品SKU）を`MAX(IF(...))`。`ranked`＝`ROW_NUMBER() OVER (PARTITION BY ref, customer_id ORDER BY d, order_name)`、初回(rn=1)・2回目(rn=2)。`grp`＝`other`→`both`→`multi`→`set`→`teiki`の順で判定。F2＝`DATE_DIFF(d2, d, DAY)<=30/60/90`。純粋新規＝`life_first = 初回注文日`。

**Q4 5-1③（3016→本品転換）**：`t3016`＝`line`で`sku='3016'`の顧客別最小日（起点）。`mp`＝顧客別の本品有償初回購入日。母集団＝`mp.first_paid IS NULL OR mp.first_paid >= origin`。転換日数＝`IF(mp.first_paid <= ref, DATE_DIFF(mp.first_paid, origin, DAY), NULL)`、同日含む＝`dd<=N`、同日除外＝`dd BETWEEN 1 AND N`。

**Q5 5-3**：`ranked`（`mion`を顧客別に通番）から顧客別`MAX(rn)`を`n_orders`とし、`COUNTIF(n_orders>=k)`（k=2〜8）をコホート月（初回購入月）別に集計。5-3-2はこの結果から計算。

**Q6 5-3-3**：`bo`＝`mion`相当に`MAX(IF(bm.product_type='定期',1,0)) AS is_teiki`を付与。`tf`＝顧客別の最初の定期注文の`rn`、`sq`＝`rn - teiki_rn + 1`を`order_seq`として`COUNT(DISTINCT IF(order_seq>=k, customer_id, NULL))`（k=2〜8）。コホート月＝初回定期注文月。

**Q7 5-4**：`reference_customer_analysis_queries.md` 8章に準拠（税抜÷1.08・`DATE_DIFF(cd.d, an.bfd, DAY) BETWEEN 0 AND N`・`cd.d <= ref`）。純粋新規＝`life_first = bfd`（`sn_shopify_customer_master`は使わず`shopify_orders`から直接算出）。
