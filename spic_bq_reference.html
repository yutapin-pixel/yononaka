    ELSE ror.receive_order_row_sub_total_price

⚠️ 必須フィルタ
FROM `spic-com-2025-apr-00.prod_dwh_oci.shopify_orders`
WHERE test = 0                  -- テスト注文除外
  AND cancelled_at IS NULL        -- キャンセル除外
  AND customer_id IS NOT NULL     -- 顧客紐付けがある注文のみ（分析によっては不要）
  AND (total_price - current_total_tax) > 0  -- 有料注文のみ（送料¥220のみ注文は別途判断）
💡 送料のみ注文（¥220等）の扱い： OGSトライアル・MINERALionトライアルは total_price > 0 AND subtotal_price = 0 のパターン。有料判定に含める場合は条件を追加すること。
🔗 line_items展開パターン（SKU別集計）
WITH items AS (
  SELECT
    DATE(created_at) AS order_date,
    JSON_EXTRACT_SCALAR(item, '$.sku')                         AS sku,
    SAFE_CAST(JSON_EXTRACT_SCALAR(item, '$.price') AS FLOAT64) AS item_price,
    SAFE_CAST(JSON_EXTRACT_SCALAR(item, '$.quantity') AS INT64) AS qty
  FROM `spic-com-2025-apr-00.prod_dwh_oci.shopify_orders`,
    UNNEST(JSON_EXTRACT_ARRAY(line_items)) AS item
  WHERE test = 0 AND cancelled_at IS NULL
)
⛔ 注文合計のブランド帰属は絶対禁止。 GE施策のプレゼントSKU（¥0）が計上されてしまう。必ず line_items の price × quantity で SKU単位に集計すること。
